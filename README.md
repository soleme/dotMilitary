# dotMilitary — 도트 군대

스무 살에 입영통지서를 받는 순간부터 이병 → 일병 → 상병 → 병장을 거쳐 전역하기까지를 그린 도트 스토리 게임입니다. 빌드 과정 없이 HTML/CSS/JavaScript만으로 동작합니다.

## 실행

```bash
python3 -m http.server 18765
# 브라우저에서 http://localhost:18765 열기
```

`index.html`을 바로 열어도 실행되지만, 브라우저가 로컬 폰트를 막아 도트 폰트 대신 기본 글꼴로 보일 수 있습니다.

## 내용

- **입영통지서**: 현역병 입영(육군훈련소·사단 신병교육대 랜덤), 모집병 지원(공군·해군·해병대·육군 기술행정병, 합격 확률), 완전 랜덤 중 선택
- **훈련소**: 군별 일정(육군 5주, 해군 5주, 공군 6주, 해병대 7주)과 미니게임(기록사격 20발, 방독면 착용 9초, 3km 달리기)
- **분류**: 전공·면허·희망을 반영한 주특기 분류, 후반기(특기) 교육, 주특기에 맞는 자대 배치
- **자대 생활**: 매월 진급·봉급·장병내일준비적금, 계절 훈련(혹한기·유격·UFS·호국훈련 등)과 랜덤 이벤트, 휴가
- **파견**: 일반명령 하달 → 출발 신고 → 파견지 임무 → 원대 복귀 신고. 원 소속 유지와 휴가 제한까지 반영했고, 수해복구·산불·ASF 방역·국군의 날·분대장 교육 등 국내 파견과 레바논 동명부대·청해부대 해외파병이 있습니다.
- **전체 진행률**: 입영·수료·진급·전역 이정표가 표시되는 진행 막대
- **BGM**: WebAudio로 만든 칩튠(기본값 꺼짐, ♪ 버튼으로 켜기)

## 테스트용 자동 플레이

`index.html?auto=1&branch=navy`처럼 열면 선택지를 무작위로 골라 전역까지 자동으로 진행합니다. `branch`에는 `army`, `navy`, `air`, `marine`, `tech`를 넣을 수 있습니다. 끝나면 `window.__done`에 결과가 담기고, 오류가 나면 `window.__err`에 남습니다.

## 고증 메모

2026년 제도를 게임용으로 단순화했습니다.

- 복무기간: 육군·해병대 18개월, 해군 20개월, 공군 21개월
- 병 봉급: 이병 75만 원, 일병 90만 원, 상병 120만 원, 병장 150만 원
- 장병내일준비적금: 월 최대 55만 원, 정부 매칭 100%
- 연가: 육군·해병대 24일, 해군 27일, 공군 28일

신병교육대 운영 현황과 부대 편성은 해마다 바뀌어 실제와 다를 수 있습니다. 해외파병 수당과 적금 이자는 게임 내 가정치입니다. 게임에 나오는 문서는 모두 가상 문서입니다.
